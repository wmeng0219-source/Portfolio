01

从简化一张表，到重新审视业务流程

存量患者挖掘空间逐渐缩小，业务希望把咬合筛查前移至儿牙日常接诊。最初提出的需求只是精简评估表。

原有业务流程

正畸快筛查看存量患者历史影像
→
面评会到诊前讨论、沟通建议
→
现场接诊儿牙医生与家长沟通
→
后续推进顾问记录与跟进

旧业务主要关系示意，并非每个患者必须依序经历四个环节。调研依据：业务流程梳理、门店走访、医生访谈、参与面评会。

四个影响业务执行的问题

01 执行负担

成本与收益不匹配

接诊时间有限，填写压力大，医生难以感知直接价值。

02 角色错位

实际分工与系统不一致

护士已承担资料采集及填写，但需借用医生账号。

03 执行差异

门店业务缺乏统一性

面评会执行不一致、重复评估、临时到诊患者难覆盖。

04 价值感知

家长不了解评估服务

专业评估多发生在门诊内部。

问题重定义：从优化表单，转向重构业务流程。
素材： 重新绘制旧业务关系图；四个问题用短标题与说明表达。不堆叠产品截图。

重新划分医疗协作中的专业职责

把资料采集、基础检查和专业判断组织为多个角色共同完成的一份筛查记录，而不是由一个医生包办。

A / 角色协作路径

护士影像分类问诊———
儿牙医生可参与可参与影像分析确认转交 →—
授权医生可查看、修正相关记录接收任务 →正式结论

主要协作路径示意，不代表严格串行或完整权限矩阵；具备正式结论权限的医生可直接下结论。

B / 岗位职责 × 专业能力等级

角色资料与问诊基础检查结论权限
护士✓——
无、一、二级正畸等级医生✓✓可选预填写
三级正畸及免审医生✓✓正式结论

表格为代表性权限关系，完整角色权限以最终系统资料为准。

C / 任务转交：默认匹配 + 手动调整

常规情况 · 默认匹配

依据已有协作关系匹配正畸医生，降低选择成本。

特殊情况 · 手动调整

考虑排班、工作负荷或现场沟通，允许选择其他具备权限的医生。

真实任务转交弹窗（局部）标注默认医生与可调整的选择入口
明确专业职责与任务交接规则，同时保留门诊现场灵活性。
素材： 影像分类界面辅助说明医护协作；转交弹窗突出默认与调整；正式结论权限局部按需使用。无需平均展示三张完整截图。
