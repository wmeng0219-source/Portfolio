问题分析

流程难以持续执行，过程难以追踪。

少数临时预约或当天来诊患者可能未被提前覆盖，是否进入评估较依赖儿牙医生主动识别与转交。

03

我的判断

识别功能重叠，整合筛查入口

我提出取消定位重叠的旧快筛，与业务共同约定过渡：先让新筛查覆盖大部分患者、完成一次评估，再退出旧功能。目前快筛已取消。

原有入口快筛 ＋ 面评表患者筛选与矫正判断部分重叠
→
当前入口统一咬合筛查分角色完成记录与专业判断

按职责与专业权限拆分任务

调研医生发现，现有表单混合了多个角色的任务，部分内容超出儿牙医生的专业能力。我提出按角色和场景拆分，让各角色接续完成记录，专业结论由正畸医生填写。

儿牙医生负责初步正畸筛查填写及家长沟通。口扫模型辅助直观解释，系统对接减少手动下载上传；试点后继续精简填写内容。

区分推荐与执行任务

业务希望固定数量并在删除后补齐。我提出按优先级分批推荐，区分推荐候选与需要执行的任务，避免不断变化的名单增加理解成本。

放弃的方案固定数量，删除后补齐持续计算与补充候选医生难以理解当天的工作范围
→
最终方案推荐池 ＋ 预约中的筛查任务高优先级自动加入原有预约医生可从推荐池主动补充

反思

信息要求要匹配现场执行能力

合理分工 → 验证现场能否完成

前期按职责拆分，试点后继续精简。我会更早验证最小必要的信息要求，并检查后续角色能否承接。

复用入口 → 先确认使用基础

业务提出独立列表后，我权衡切换成本与正畸流程差异，通过医生调研确认方案可接受，最终选择拆分。
