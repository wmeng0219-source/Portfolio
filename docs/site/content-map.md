## 02 Portfolio / Selected Work (精选项目)

- 核心结构：每个项目统一为 **“场景 ➔ 真实问题 ➔ 我的关键决策 ➔ 三段式结构化结果”**。

### 项目 1：会员与收银自动化 (Membership & Billing)
- 场景定位：规则复杂度治理
- 我的角色：产品设计 · 业务规则梳理
- 真实问题：会员卡、卡券、储值及跨店规则复杂，导致收银高度依赖人工判断，效率低且存在财务风控隐患。
- 关键决策：将会员权益、优惠权限与收费规则结构化，由系统自动计算可用权益与应收金额，去除低效审批流。
- 结构化结果：
  - `~80% ↓` 单笔结账耗时 (4-5min ➔ ~1min)
  - `20+ 门店` 全流程自动化运行
  - `降低风控` 规则系统化，减少违规操作空间

### 项目 2：正畸筛查与协作流 (Orthodontic Workflow)
- 场景定位：协作复杂度治理
- 我的角色：产品设计 · 流程重构
- 真实问题：原先正畸筛查仅靠单次粗暴看照片判断，角色间信息独立断裂，缺乏全流程跟踪，重点客户流失严重。
- 关键决策：把孤立的一次性筛查，重构为诊室内的多角色精细化协作机制，辅助医生在最佳时机与家长科普铺垫，形成持续跟踪流。
- 结构化结果：
  - `50–60%` 重点客户转化率 (原 30-40%)
  - `全流程` 跨科室状态流转结构化可追踪
  - `持续管理` 从诊室初筛、报告出具到最终预约

### 项目 3：PACS 影像 AI 辅助读片 (Diagnostic AI)
- 场景定位：认知与人机复杂度治理
- 我的角色：交互架构设计 · PRD 撰写与需求定义
- 真实问题：影像读片依赖医生个人习惯，缺乏系统性质控机制，存在漏读风险；且 AI 初筛结果与医生临床工作动线脱节。
- 关键决策：将 AI 初筛深度嵌入医生读片动线，通过轻量交互引导快速复核，建立读片率质控机制与数据反馈闭环。
- 结构化结果：
  - `+140%` 均单龋齿检出能力提升 (1.43 ➔ 3.46 颗)
  - `全流程` 读片状态可追踪、可质控
  - `人机闭环` 医生复核结果沉淀为算法迭代反馈

## 内容准入与更新顺序

案例是否进入页面，不由文案完成度决定，而由事实与证据就绪度决定。更新前先检查 `../project/content-readiness.md`，再按以下规则取材：

| 页面位置 | 最少应承接的内容 | 不应承接的内容 |
| --- | --- | --- |
| 首页项目入口 | 项目命题、个人角色范围、一个有口径的结果、查看详情的理由 | 长背景、功能清单、没有来源的强结论 |
| 案例详情页 | 现场、根因、约束、决策、机制、落地、结果与反思 | 只展示高保真图或纯项目过程日志 |
| About / Experience | 职业演进、真实职责范围、可迁移的工作方式 | 与项目详情重复的指标与功能说明 |
| More Cases | 有清晰问题和机制、但证据尚不足以承担首页主案例的项目 | 用未验证成果补充数量 |

首页三个主案例继续分别证明：规则与治理、流程与协作、人机边界。任何新案例进入首页前，必须说明它补足了什么能力，而不是重复已有案例。
