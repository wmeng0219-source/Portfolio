# 站点注册与结构

这里维护全站产品定义、页面准入、路由和结构，不承担单页内容审核或逐字文案维护。

- [product.md](product.md)：根据页面底稿整理的网站目标、读者路径、页面职责、内容摘要与功能要求。

- [content-map.md](content-map.md)：页面注册、案例定位、事实与工作文件路径。
- [structure.md](structure.md)：代码和资料目录职责。
- 内容、设计审核入口统一见 [文档总览](../README.md)。

全站定位、读者路径、页面新增、准入、路由或区块职责变化时更新本层；逐字标题、摘要、指标文案改动在对应内容稿内处理，不另建文案审核稿。
