### 【第 3 块】工作方法 (HOW I WORK)

* **英文标签 (Eyebrow)**：`02 / HOW I WORK`
* **区块大标题**：`工作方法 · 我如何把复杂问题变成系统`
* **区块引导语**：`从混乱复杂的业务现场出发，通过 5 步严密的产品思考流，把模糊问题收敛为稳定运行的产品系统。`
* **5 步连贯贯穿式流程图谱 (纯知识展示，非可点击列表)**：
  1. **`01 / Understand` (深入现场)**
     * 深入业务一线，理解各角色的真实痛点、操作习惯与流程断点。
  2. **`02 / Frame` (定义问题 · 核心关键)**
     * 辨别是规则缺陷、协作断裂还是信息缺失，把一线零散的抱怨收敛为明确的产品命题。
  3. **`03 / Structure` (系统建模)**
     * 将业务经验转化为显性规则、状态机、权限边界与自动化闭环。
  4. **`04 / Validate` (真实验证)**
     * 通过高保真可用原型与灰度环境，验证交互体验与业务方案的可行性。
  5. **`05 / Iterate` (持续演进)**
     * 根据一线运转数据与反馈，持续优化系统的稳定性、效率与易用性。
