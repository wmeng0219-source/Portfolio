# Hero Section Figma Redesign Plan (Corrected: Centered Alignment)

## 背景与目标
根据用户提供的 Figma 链接（node-id=140-83），我们需要重构 Hero 区块。
经过重新提取和分析画板内容，确认设计意图为**居中对齐**的极简编辑风，而非先前错误推断的左对齐。

## 核心视觉与布局特征
1. **纯粹的深色背景**：移除现有的发光特效、网格和光晕等复杂背景元素。
2. **极简居中排版**：内容区域在屏幕中央垂直与水平居中。
3. **巨大的中文字体排版**：采用大字号、紧凑行高的段落式标题，文案如“数字化、流程重构与AI协作，在混乱的执行中，建立可观察的系统闭环。”
4. **高级胶囊按钮**：深色背景、细边框、大圆角的“联系我”按钮，体现高级克制感。

## 实施步骤
1. **清理 `index.jsx` DOM 结构**：
   - 移除 `<div className={styles.stageBackdrop}>` 下的所有复杂特效节点。
   - 移除多余的装饰性层级，保留纯粹的文本容器和按钮容器。
   - 将原有的四行 `h1` 和副标题段落合并或简化为符合 Figma 设计的大段落结构。

2. **重写 `Hero.module.css`**：
   - **布局**：使用 `flex` 居中对齐，高度设为 `100vh`（或类似满屏比例）。
   - **文本**：应用极端紧凑字距（`letter-spacing: -0.05em`）、合适的响应式字号（如 `clamp(2rem, 5vw, 4rem)`）和居中对齐。
   - **按钮**：实现细白边框、半透明黑底的胶囊样式。

3. **保留 GSAP 动画**：
   - 仅对文本行和按钮保留优雅的从下向上浮现（`y` 轴位移 + 透明度）动画。
