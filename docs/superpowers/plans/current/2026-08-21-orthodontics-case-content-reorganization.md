# 正畸案例内容重梳实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 依据正畸筛查原始材料，把现有案例重写为招聘者可读的深度案例，清晰区分流程机制、个人责任、试点演进和转化数据。

**技术栈：** Markdown、`rg`、Git diff；事实来源为 `docs/origin/咬合筛查/`，视觉规范服从根目录 `DESIGN.md`。
