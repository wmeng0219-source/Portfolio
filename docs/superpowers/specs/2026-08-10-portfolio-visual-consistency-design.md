# 作品集视觉一致性设计规格

## 目标

统一首页和三个案例详情页的视觉基础，解决容器宽度、对齐、字号、间距、圆角、边框、悬停反馈与响应式行为不一致的问题，同时保留会员自动化、正畸筛查、PACS AI 各自的内容结构和项目表达。

## 设计边界

- 不修改项目事实、数据口径、路由或案例顺序。
- 不引入新的组件库、字体下载或装饰性动效。
- 首页与案例详情页共享同一套 CSS 设计变量；案例仍保留独立 JSX 与 CSS Module。
- 当前仓库没有 Neudron 与 GT America 字体文件，因此按规范声明它们为首选字体，并使用 Hanken Grotesk、Inter 作为可靠回退。

## 视觉系统

### 色彩

- 页面背景：`#0d0c11`
- 卡片背景：`#16151c`
- 抬升表面：`#1f1d26`
- 发丝边框：`#2a2833`
- 薰衣草紫：`#d0bcff`
- 薄荷绿：`#b9f2c8`
- 主文字：`#f2f2f5`
- 正文：`#aaa6b3`

颜色只承担层级、交互和状态语义，不增加第三强调色。

### 字体与字号

- 标题：`Neudron`，回退到 `Hanken Grotesk` / `Inter`。
- 正文：`GT America`，回退到 `Hanken Grotesk` / `Inter`。
- 标签和数据：`IBM Plex Mono`。
- 所有标题、正文、标签和数据字号均使用 `clamp()` 设计变量。
- 统一案例阶梯：H1、H2、H3、正文、标签、指标六级，不在各页面重复定义同级字号。

### 布局与间距

- 最大内容宽度：`1280px`。
- 横向页面留白：`clamp(1.25rem, 4vw, 4rem)`。
- 常规区块纵向留白：`clamp(4.5rem, 8vw, 8rem)`。
- 紧凑区块纵向留白：`clamp(3.5rem, 6vw, 6rem)`。
- 间距遵循 8px 网格；主要组合使用 16、24、32、48、80、120px。
- 桌面端内容左边界统一，双栏使用一致的列间距；低于 768px 后切换单栏。

### 组件

- 内容卡片统一 `16px` 圆角、`1px solid #2a2833` 边框。
- 小按钮、标签、内部媒体框使用 `10px` 圆角。
- 卡片 Hover 统一上移 `2px`，边框切换为薰衣草紫并增加克制辉光。
- 导航栏在三个详情页使用相同高度、容器、留白和返回链接样式。
- 焦点态可见，动效遵循 `prefers-reduced-motion`。

## 页面调整

### 首页

- 将 Portfolio 区域从散乱 Tailwind 字号和间距改为语义类。
- 统一三个卡片的边框、圆角、标题、正文、标签、数据和 Hover。
- 保留一张主案例卡 + 两张辅助案例卡的现有结构。

### 会员自动化与 PACS AI

- 共享相同的 Hero、Section、H2、正文、标签、卡片和响应式数值。
- 保留各页面不同的图像与项目模块。

### 正畸筛查

- 从独立的 `1000px` 页面改为统一的 `1280px` 内容容器。
- Hero、时间线、角色 Tabs、决策卡和结果卡接入统一类型与圆角变量。
- 五段项目时间线在中等屏幕改为可读的多列/单列布局，避免挤压。

## 响应式验收

- 1440×900：内容容器与各区块左边界一致，同级标题和正文一致。
- 1024×768：间距收紧，网格保持可读，无卡片内容溢出。
- 390×844：双栏全部变为单栏，指标与时间线可自然换行，无横向溢出。
- 所有尺寸下卡片圆角为 16px，内部控件为 10px，Hover 位移不超过 2px。
