## 二、 视觉与交互要点

### 指标呈现
- 首屏指标卡采用 **Before / After 对比**（`Mint #b9f2c8` 标记成果）：
  - 单笔升级操作耗时：`4-5 min` → `1 min`
  - 月底财务对账周期：`3 天` → `1 天`（标注"据财务团队估算"）
  - 网络覆盖规模：`20+ 门店`
- 指标数字与 `docs/project/会员自动化.md` 保持一致，禁止页面层新增口径。

### 机制可视化
- **核心可视化对象**：规则引擎（多卡种 / 权益 / 优惠额度 / 跨店账单的判定逻辑）。
- 推荐使用 `ProjectBlueprintCover`（规则矩阵构图）：会员输入 → 规则判定 → 输出 + 异常虚线路径。
- 异常兜底场景（多账单、无账单、冻结、退卡、跨店、额度不足）用状态色区分，不做大面积辉光。

### 交互形态
- 决策对比（自动匹配 vs 人工选择；审批逐笔 vs 额度化治理）用 A vs B 对照区块。
- 边界状态用渐进式暴露，避免全量铺开。
