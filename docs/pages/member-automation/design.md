# 会员自动化页面设计说明

> 2026-11-09，按反馈统一会员页字体，完善办理对照、分支、步骤和结果的图形表达，待用户验收。正式内容见[content.md](content.md)，通用值见[DESIGN.md](../../../DESIGN.md)，组件契约见[COMPONENTS.md](../../../COMPONENTS.md)。

## 1. 页面目标

面向用人经理证明：作者能将散落在卡、券、账单与人员经验中的业务关系，转成可查看、可判断、遇到中断仍能继续的产品流程。办理流程重构是主要案例段落；优惠授权作为独立的第二项关键设计，展示另一项判断，不降为附属功能。

页面从封面价值摘要进入业务背景、办理流程重构、优惠授权与约束及落地结果。以补差价换卡的场景解释旧工作方式，随后说明自动与人工的分工，最后分别交代观察、能力和保留的边界。

## 2. 构图与阅读组织

中文版采用纯文字深色封面，粉色标题、简介、数字和职责对齐正文左轴。白底正文保留桌面左侧目录和稳定的阅读轴，证据区沿正文左轴向右展开。每张完整截图与图名、解读共用一个图框。平板与手机将目录放回文档流。

| 阅读段落 | 主次与视觉单元 |
| --- | --- |
| 封面 | 项目价值之后并列典型耗时与推广范围，标明现场观察口径，接一行本人职责 |
| 会员业务与改造背景 | 从家长补差价换卡开始，用关系图串起原卡、权益与收费账单，再对照改造前后并交代保留领健的原因 |
| 会员办理流程重构 | 工作台和选卡并排，显示同一工作环境下的两次核对。账单选择用整行截图，中断与完成按相同尺度并排对照 |
| 优惠授权与约束 | 从逐笔审批与现场收银的冲突引出个人月度额度。Bento 主格展示完整超额界面，说明格列出输入、校验与限制确认三个步骤 |
| 落地结果与边界 | 用试点与推广数字开场，分别交代使用反馈、观察口径、已实现能力和保留的人工工作 |

四个目录锚点为overview、solution、governance、impact；旧problem入口归到overview，旧decisions入口定位到原账单判断，滚动到章节后将焦点移至对应内容。

## 3. 内容视觉化

表达选择遵循DESIGN §4.7。正式事实、贡献与口径以content.md为准，页面提炼不另建内容审核稿。

| 信息关系 | 表达与真实证据 | 能证明／不能证明 |
| --- | --- | --- |
| 升级牵涉三类记录 | 从当前会员卡分支到服务权益和原收费账单 | 连线表示对应关系，不代表操作或接口顺序 |
| 改造前后的工作方式 | 领健和 ODOS 两条办理路线，按查记录、算差价、办理三个环节对齐 | 每列说明前台与系统的分工，箭头表达办理次序 |
| 患者现状与本次购买 | 完整工作台和带选卡弹窗的完整界面等宽并排 | 两张图各自承担一次核对，图注指出相关区域 |
| 原账单依据是否明确 | 条件和处理方式逐行对应，突出截图演示的多笔候选分支 | 唯一时自动算差价，多笔候选时核对收费时间、门店、实付、就诊信息与备注，无账单回领健 |
| 已完成与尚未完成 | 中断与完成的完整界面等宽并排 | 图注说明哪些操作保留，以及员工去哪里继续 |
| 优惠授权范围与输入约束 | 完整手动优惠界面配编号和连线串起的校验步骤 | 图注说明示例金额、剩余额度和确认状态，账单使用记录依据内容底稿 |
| 观察与推广 | 结果章分别用两阶段数字对照表示门店推广与典型耗时，观察来源紧贴对应数字 | 两组数字各自标明单位与阶段；耗时前后取自调研和现场观察 |

## 4. 局部特例

<a id="6-图组亲密性与统一图注当前补充采用值"></a>

| 范围 | 当前采用与边界 |
| --- | --- |
| 阅读与字体 | 会员中文版统一采用 Noto Sans SC 无衬线字体栈，覆盖封面、导航、正文、图注与数据。正文采用 16px / 28px，标题网格 720px，图文列 672px。此特例覆盖 DESIGN §4.6 的默认同宽配方 |
| 业务关系图 | 桌面借用 720px 标题网格，图框、正文与截图共享左轴。窄屏回到正文列内 |
| 办理章样板节奏 | 以[已通过的样板源码](../../../output/harrison-background-study/member.html)为依据。1440px 下章标题为 44px，行高 1.6，标题后 18px。小标题为 16.8px，前后间距为 28px 和 8px，正文段后 16px |
| 图片与图注 | 桌面证据区沿正文左轴展开，宽度封顶 944px。截图保持原比例，图名和解读紧接截图，使用阅读媒体底、1px 轮廓与 8px 圆角。两组对照使用等宽双格，格间距引用 DESIGN §5.7 |
| 错误与查看 | 点图或键盘激活可放大同一张完整图。查看器按窗口等比展示，操作区仅保留关闭按钮。加载失败保留图注，支持 Escape 关闭并返回触发焦点 |
| 视口边界 | 1280px 起优惠校验采用主图加说明格。1101px 起启用并排对照，较窄视口内证据按正文列单列堆叠。手机上关系图保留纵向分支 |
