# 会员自动化页面设计说明

> 2026-11-19 规范精简。本文记录当前页面的设计理由、素材与审核状态；正式内容见[content.md](content.md)，唯一设计规范见[DESIGN.md](../../../DESIGN.md)。本轮只调整文档职责，不改页面或既有验收结论。

## 1. 页面目标

面向产品与设计招聘官证明：作者能把分散在卡、券、账单与人员经验中的业务规则，组织成可核对的决策流程，并明确自动处理、人工接手与优惠授权的边界。

核心论证沿业务约束推进：保留底层能力的架构选择 → 聚合办理依据 → 为数据歧义与中断设计人工入口 → 将优惠授权提前到交易当下 → 区分观察结果、已实现能力与后续方向。页面以阅读为主，真实界面用于证明判断，不以功能数量或装饰动效组织章节。

## 2. 构图与阅读组织

当前方案采用纯文字深色封面、粉色标题、白底正文和桌面左目录，正文与证据分配不同宽度。这里记录已实施的阅读关系；图文比例、字阶和证据细读方式可在统一基础上优化。

| 阅读段落 | 主次与视觉单元 |
| --- | --- |
| 首屏 | 三栏并排展示办理效率、财务治理能力、推广范围，仅保留标签与核心变化；口径在结果章解释，职责收敛为横向文字标签组 |
| 业务背景与架构取舍 | 家长补差换卡场景起笔；左右架构图比较原系统独立模块与新系统聚合工作流；沿用左右比较容器，对照整体重做与增量封装的范围与代价 |
| 策略一：信息架构重构 | 工作台与升级选卡上下两行，每行完整截图与设计解析并列 |
| 策略二：跨系统容错设计 | 先列唯一／多笔／无账单分支，接账单选择大图＋解析；中断界面作为重点展示，成功反馈缩为下方对照辅图 |
| 策略三：风控前置治理 | 优惠券与手动优惠先按相同维度左右比较，再展开额度授权、即时阻断和留痕；超额图保留原主图＋步骤布局；新增会员操作日志完整图 |
| 落地验证与演进 | 保留推广与耗时两组对照；已实现机制和观察结果分别表述；最后说明新入口外的边界及尚未实施的建议 |

五个目录锚点为 overview、solution、resilience、governance、impact；旧 problem 继续指向 overview，旧 decisions 保留在 resilience 章原账单判断位置。重复点击、深链接与焦点定位沿用现有行为。

## 3. 内容视觉化

表达方式依据统一规范和本页判断选择，正式事实与贡献以 content.md 为准。

| 信息关系 | 表达与真实证据 | 证明范围 |
| --- | --- | --- |
| 改造前后业务分工 | 左侧三个原系统模块以虚线汇入前台人工串联；右侧统一入口组织核对、补差和接口执行 | 业务分工示意，不表示具体接口调用顺序 |
| 确认现状与本次购买 | 工作台、选卡界面各自完整展示，旁边解释相应设计判断 | 证明信息聚合与报价核对，不凭截图推导节省时间 |
| 原账单匹配是否确定 | 三分支列表＋完整账单选择图 | 无歧义自动处理；有歧义人工确认；无依据阻断 |
| 已完成与尚未完成 | 中断图为主、成功图为辅，文字说明状态与人工去向 | 已完成结果保留；不存在整笔自动恢复承诺；界面不是故障实测 |
| 优惠授权与输入约束 | 超额完整界面＋输入／校验／确认三步 | 示例金额只解释机制，不能作为经营结果 |
| 优惠使用与会员变更 | 账单留痕由已确认业务说明支持，操作日志图支持会员变更追查 | 两类记录分开解释；日志图不能代证优惠使用看板或完整财务监管 |
| 结果与后续方向 | 推广、耗时分别比较，观察口径就近说明；演进建议单列 | 不生成新比例、不把推广当采纳、不把建议当项目成果 |

## 4. 当前呈现与阅读行为

<a id="6-图组亲密性与统一图注当前补充采用值"></a>

当前为窄正文配宽证据、截图与解析并列的五章页面。原固定字号、宽度、比例和间距不再作为本页独立规范；后续按论点和实际可读性主动调整，不要求沿用旧样板或每图三条解析。

- 工作台与选卡建立办理上下文；中断为主证据，成功为状态对照。完整图片保留查看途径，关键字段也需要在正文中可辨认。
- 业务分工、架构取舍和优惠规则采用对照表达，含义与证明范围由第 3 节及内容底稿约束。
- 顶栏、目录和锚点互相避让；查看器保留原图、关闭按钮、Escape、加载失败说明与焦点返回。
- 当前组合仍为本页实现，没有因登记用途而完成跨页组件化。源码入口：[页面与查看器](../../../src/pages/cases/MemberAutomation/index.jsx)、[叙事与解析](../../../src/pages/cases/MemberAutomation/Narrative.jsx)。
