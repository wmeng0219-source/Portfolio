## 一、 页面呈现结构

按 `content.md` 的 7 步证据链渲染：
1. Hero 首屏
2. 背景与业务挑战 → 问题发现 → 设计目标 → 方案对比 → 关键设计决策 → 核心模型 → 角色协同 → 成果 → 复盘

> 本项目为**深度候选/扩展案例**，页面定位以展开叙事为主，可承载比首页短卡更长的内容。

## 二、 视觉与交互要点

### 核心可视化对象
- **跨系统信息整合**：网络电话 / 领健收费 / 360 病史三大系统孤岛 → 统一全景视图。
- **任务编排引擎**：全景视图 → 规则推荐任务包 → 医护运流转 → 自动同步病历。
- **设计驱动产品**：交互推演 → 产品规则收束 → PRD（可展示"设计反向驱动规则"的过程材料）。

### 机制可视化
- Before / After 流程对比（跨系统手工拼接 vs 任务编排引擎）。
- 关键设计决策（抽屉式推荐理由、十字牙位选择器、预习时效校验）用决策对比区块。
- 多角色流转（护士 / 医生 / 运营）用协作链呈现。

### 交互形态
- 可解释推荐用"抽屉展开"隐喻呈现。
- 十字牙位控件可作为该页的特色视觉元素。
