# PACS 页面设计说明

> 2026-11-19 规范精简。本文记录当前页面的设计理由、素材与审核状态；正式内容见[content.md](content.md)，唯一设计规范见[DESIGN.md](../../../DESIGN.md)。本轮只调整文档职责，不改页面或既有验收结论。

## 1. 页面目标

帮助读者理解如何在讲片过程中留下与影像对应的记录、如何追踪完成情况，以及AI线索与医生责任的边界。原七部分、职责、判断与对应方案、数据和限制保持，不增加医疗或效率结论。

## 2. 构图与阅读组织

当前采用深色自然高度封面、白色连续阅读、左目录和编号标题。正文与证据的宽度可分别按阅读需要校准，不再以固定双轨配方或另一案例的尺寸作为约束。

封面标题与简介沿正文左轴，文字围绕当前阅读轴组织；正文职责、列表、小标题、图形同轴，具体行宽依据真实内容判断。当前正文首章为“我的职责与协作”H2，目录为“项目概览”。React、CSS Modules和独立案例模块保持。

## 4. 当前呈现与阅读行为

当前为深色封面、白色阅读区、侧目录与编号章节。原固定轨道、颜色微差、节点圆角和数字字阶不再形成独立规范，后续可依据真实素材与阅读效果校准。

- 封面、职责首章与方案锚点各有定位；目录“项目概览”和首章正式 H2 的现有区别保留，原七章与方案链接可直达。
- 完成状态、同步机制与 AI 复核是不同的业务关系；图形表达继续遵循第 3 节的语义边界。
- 结果使用开放数据行，管理目标与真实数据分别呈现；不要求数据都进入同一种卡片。
- 当前保留本页窄屏目录和布局，不因文档精简复制其它案例实现。页面与表格见 [PacsAiPage.jsx](../../../src/pages/cases/PacsAi/PacsAiPage.jsx)，业务图形见 [visuals.jsx](../../../src/pages/cases/PacsAi/visuals.jsx)。

## 5. 素材使用

详情仍有三个明确占位：完整读片工作台、医生手动结构化读片、AI提示与对应卡片。占位是命名灰底区域，不用未脱敏旧图、AI重绘牙片或封面样机冒充证据；相关规则示意不能关闭截图缺口。

首页当前封面为已确认V7鼠尾草绿正面显示器样机，资产[public/images/pacs/pacs-cover.jpg](../../../public/images/pacs/pacs-cover.jpg)，当前自然比例整图显示，工具栏与底座完整，不替代详情原始截图。版本与提示词见[生成记录](../../../output/pacs-cover/generation.md)。

脱敏、真实系统截图和其它证据就绪状态唯一见[证据备注](content.md#86-证据与素材待补内部)。
