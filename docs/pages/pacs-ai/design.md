# PACS 页面设计说明

> 正式文案：[content.md](content.md)。通用采用值：[DESIGN.md](../../../DESIGN.md)。本页无突破全局阅读器的数值特例；下述呈现映射为V4目标，运行页仍为旧深色实现。

## 1. 设计方向

使用深色展示封面与白色连续阅读。面向招聘方，让读者先理解项目，再依次读问题、判断、方案、机制、结果与反思；七部分及三组判断和方案关系不变。没有首屏数字战果，不把正文做成七张大卡。

PACS作为首个视觉样稿，验证较长项目介绍、双语标题、目录、证据、流程与数据。它是优先深入的案例，不改变首页第三卡的位置。

## 2. V4布局目标

独立路由`/project/pacs-ai`保持。采用DESIGN.md默认浮动阅读器：深色双列封面、白色目录/阅读列/平衡列；职责在正文首区连接完整工作台证据。手机封面同轴、阅读单列，目录从顶栏入口展开完整章节；低高度自然增高，不隐藏正文。

概览定位封面；目录与章节id对应，重复定位、高亮、安全距离、目标焦点及reduce即时定位遵循通用Reader契约。正式标题与介绍完整，辅助顶栏可截断。

## 3. 各章节如何呈现

以下只说明布局，正式文案和素材要求仍在 content.md 对应章节维护，不在这里复制。

### 项目概览

深色封面放暂用标题与项目介绍，桌面两等列、手机同轴左对齐；白色正文首先呈现“我的职责与协作”两段普通文字，再接完整工作台占位。目录“项目概览”定位封面，职责区不再显示重复的大章节标题。正式文字与个人归因不变；字体角色引用DESIGN.md §3.4。

标题继续使用内容稿的暂用标题。项目周期未确认，不展示空日期或从统计周期推算。首屏不加入使用量、AI 占比或管理目标。

### 问题

先用一条原流程示意建立现场，再纵向呈现管理人员和医生的两类问题。以小标题与留白分隔，不做两张等权人物卡。示意图注明根据真实流程整理，不冒充旧页面截图。

### 我的判断

用三组纵向对应关系呈现“问题 → 判断 → 对应方案”。A / B / C 在后面的方案标题沿用，便于回看；三组之间用细分隔线，不用三个彩色大卡片。

判断正文保持可读，图形只承接已确认关系，不新增被否决方案、处置或任务推送。快速选择与复用共同归入 B，不再次拆成独立判断。

### 方案

这是图文最集中的部分。每组先说明理由，再展示对应截图或示意；只在短说明与局部截图能够对应时使用双栏，复杂工作台使用宽图。

- **4.1**：先说明完整内容为何进入病历，再用检查表与病历关系示意或真实截图呈现同步。明确护士上传时已关联预约；同步动作发生在检查表，不把“完成读片”按钮画成发送病历的入口。
- **4.2**：用一张宽工作台图承接标记与文字对应；将快速选择、搜索及复用的局部展示放在相应段落附近。复用是该节的一部分，不另起大章节。只用编号定位界面部位，不添加未经提供的医生原话。
- **4.3**：AI 提示截图之后呈现三种复核选择及后果，保留内容稿表格关系；超时或失败的手动入口放在同节末尾。三种选择不用三个不同品牌色表示，也不包装成实际准确率。

### 系统机制

使用一张主流程图，配合三种读片状态及同步规则。主流程先从护士上传、关联预约讲到医生读片，再讲检查表同步；未见明显异常的明确确认与无法读片不得混为一条结果。

AI 是可选辅助，不画成所有路径的必经步骤。状态表单独说明完整、未读与不完整的处理，不把“已读片”表现为医学判断正确。特殊情况用简短列表承接，不扩展成第二套系统架构。

### 结果

先以三条开放式文字行说明医生与医护、管理人员、AI 辅助已具备的能力，再说明读片完成率的口径和动态目标。目标与真实使用数据分区，60% 不做成已达成的进度条。

使用数据以深色数字、开放式分隔的三项数据行呈现，每项保留单位、解释和已有时间口径；数据限制紧接其后。各项不连成漏斗，不制作虚构监控看板，也不恢复已删除的 6.3。

### 反思

回到窄幅文字阅读，以“少打字，不等于填写更快”为主要焦点。先讲上线后医生反馈，再讲设计不足和如果重做会如何判断；不把反馈改写成耗时统计或已完成的优化。

AI 记录选择的反思作为次级小节，保持内容稿原文。不再加总结卡、能力标签或新的口号。

## 4. V4视觉与交互目标

全部字体、颜色、尺寸、间距、圆角、阅读对齐与动效引用DESIGN.md §2–7，不复制数值。正文和证据共用阅读轴，结果数字使用浅色阅读场景的深色文字；连续长文保持固定阅读角色，不机械套8px网格或闭合卡片。目录、返回、语言、焦点与实际阅读进度按通用组件契约实现，reduce显示完整正文并即时定位。

这些是目标与样稿规则，当前深色运行页仍待迁移。

## 5. 素材与响应式

截图仍使用“素材准备中 / Image pending”的名称与用途占位，不放未脱敏旧图、假牙片、假标记或虚构医生反馈。缺口由content.md与content-readiness维护，不把布局占位验收当作证据已齐。

流程图按真实路径；手机转纵向，表格局部滚动、整页不横向溢出。截图contain/自然比例，图注不小于14px；所有触控目标≥44px，目录与返回有明确焦点。
