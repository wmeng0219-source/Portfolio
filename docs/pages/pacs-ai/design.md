# PACS 页面设计说明

> 2026-11-06 职责整理。正式内容与就近配图论点：[content.md](content.md)；通用值：[DESIGN.md](../../../DESIGN.md)；用途及状态：[COMPONENTS.md](../../../COMPONENTS.md)。本轮只整理规范，不改变页面、文案或已有审核结论。

## 1. 页面目标

帮助读者理解如何在讲片过程中留下与影像对应的记录、如何追踪完成情况，以及AI线索与医生责任的边界。原七部分、职责、判断与对应方案、数据和限制保持，不增加医疗或效率结论。

## 2. 构图与阅读组织

采用DESIGN §4.6主案例双轨同宽及分隔章节节奏。由原“按正畸规范”改为直接引用共享配方，不再依赖另一页面解释通用值；保留本页深色自然高度封面、白色连续阅读、左目录、编号标题和统一图文宽度。

封面标题与简介沿正文左轴，封面文字宽度引用共享配方；正文职责、列表、小标题、图形同轴，不恢复690px限制。正文首章保留既有“我的职责与协作”H2，目录仍为“项目概览”，不因共享结构改正式标题。React、CSS Modules和独立案例模块保持。

详情仍有三个明确占位：完整读片工作台、医生手动结构化读片、AI提示与对应卡片。占位是命名灰底区域，不用未脱敏旧图、AI重绘牙片或封面样机冒充证据；相关规则示意不能关闭截图缺口。
