## 1. 设计边界

采用与[正畸阅读页](../orthodontics/design.md)一致的深色自然高度封面、白色连续阅读层、左侧目录、统一图文宽度和编号标题。保持现有 React、CSS Modules 与独立案例模块，不增加依赖，不改首页及其他案例的样式。

七部分、正式标题、段落、职责、判断 A/B/C、方案 4.1/4.2/4.3、数据及限制说明全部保留；`content.md` 与运行时 `content.js` 均未改动。为避免改写章节内容，正文首章仍使用既有“我的职责与协作”H2，目录沿用“项目概览”，英文眉题为 PROJECT OVERVIEW。

## 2. 页面局部采用值

以下仅覆盖 `/project/pacs-ai`，按本轮用户要求显式采用正畸阅读规范，不将这些局部值推广到其他页面。

- **颜色与字体**：白底 `#fff`，标题 `#171717`、正文 `#363636`、辅助说明 `#5c5c5c`；Action ink `#624595` 用于目录、编号与关系线。中文 Noto Sans SC，结构文字 Hanken Grotesk，辅助标签 IBM Plex Mono，章号及 PACS 拉丁标题 Anton。保留本站已有字体，不另换品牌字体。
- **共同容器**：最大宽度 1320px，PC 左右 48px；目录 180px、列距 48px。861–1079px 左右 32px、列距 40px；更窄保留单列基础布局，本轮不展开移动端专项。
- **封面**：`#080808`，上 100px / 下 52px 自然高度；标题与简介沿正文左轴，文字最大 672px。中文标题 `clamp(36px,3.5vw,50px)/1.25/700`；简介 `clamp(16px,1.5vw,19px)/1.8`，组间 24px。不添加未确认项目周期或数字战果。
- **正文与图形同宽（2026-10-24用户返修）**：阅读区上下64px / 80px；正文、职责、列表和小标题取消原690px局部上限，共用章节与图形最大938px的左右边界。正文16px / 28px、段后16px，中文两端对齐且末行左对齐。正文与标题显式使用 `text-wrap: wrap`，覆盖全局 `pretty` 对行尾的自动调整；按实际容器宽度自然换行。此项为用户本轮明确覆盖正畸“两种内容宽度”的PACS页面特例。
- **七章标题**：70px 编号槽、列距 16px；编号 Anton 59.4px/.95，与 12px 英文眉题、28px/1.3 中文章名组合。组后 28px；章前 64px、细线及上内边距 24px。长章名自然换行，编号不随标题总高度拉伸。小标题18–20px/1.5/600，前32px、后12px；保留全部原有标题。
- **图形**：图前 28px、后 24px；白底、细紫灰边框、6px 圆角，中性浅底承载节点。图题20px/1.5/600；图注14px/1.65。关系线只表示已确认业务关系，不加入额外数据、医疗结论或虚构产品界面。
- **数据**：三个不同单位的数据使用开放式行布局，数值采用 tabular-nums 与深色文字，旁列完整说明。60% 管理目标单独配原文说明，不绘制为已达成进度，也不与累计使用数据连成漏斗。

### 图形含义与事实边界

1. **检查表同步路径**：已完成读片 → 检查表同步按影像状态筛选 → 病历辅助检查；明确确认未见明显异常也属于已完成读片。图形不把“完成读片”按钮描述为同步病历入口。
2. **内容复用**：已有完整标记的密度、诊断、描述带入新标记；新标记保留自身牙位与方位，仅在三项为空时可复用，仍由医生确认适用性。
3. **AI复核**：将原文表格改为“AI提示 → 医生复核”后的三条独立结果行。选择与后果完整复用原文；正确且继续、正确但本次不记录、判断错误分别呈现，不等同为AI准确率。
4. **手动继续**：超过5秒或调用失败时，可选择手动读片，仍执行相同必填检查；不画成免除完成要求。
5. **影像类型**：确认或纠正类型后，根尖片/咬翼片支持AI或手动，全景片手动且不展示AI数据。AI为可选辅助，不是全部影像必经节点。
6. **主流程与状态**：六个节点逐项保留原流程文字，明确护士上传关联预约、医生从检查表进入、完成状态判断和检查表同步；状态只追踪完成，不判断诊断正确性。

以上均标注为根据已确认规则整理的示意，不是原始产品截图。图形与表格仍使用可访问的列表、定义列表与表格元素。

## 4. 导航与交互

- 封面独立为 `#case-cover`；`#overview` 定位正文职责首章。原有七章锚点及三个方案锚点均保留，不改路由准入。
- PC目录sticky top100px；章节与方案锚点 scroll-margin-top100px。点击章节后把焦点交给章标题，重复点击同一链接仍可定位。
- 保留离散 IntersectionObserver 高亮和resize清理；顶栏随封面离场变为浅色。返回链接仍回首页项目区。
- 保留键盘焦点、reduce即时定位及基础窄屏布局。英文入口继续暂停，既有英文数据与恢复逻辑保留，不开展英文专项。
