# 首页设计规范 (Homepage Design Spec)

> **文档定位**：本文档定义首页的**视觉样貌、交互形态、布局与动效**，是首页"长什么样 + 怎么交互"的设计母稿。逐字文案与区块叙事见 [`content.md`](./content.md)。全局设计基础（配色、字体、圆角、间距、组件风格）见根目录 [`DESIGN.md`](../../DESIGN.md)。

---

## 一、 核心定位与设计原则

* **个人核心定位**：具有设计背景的系统型产品经理（Product Manager for Complex Systems · Design-driven）
* **能力层级逻辑**：
  * **Product** 是核心主干（业务判断、规则定义、系统边界与结果落地）；
  * **Systems** 是核心特长（擅长处理规则、协作、人机等各类复杂系统）；
  * **Design** 是坚实底座（比传统 PM 更懂用户体验、信息架构与高保真原型验证）；
  * **AI** 是能力放大器（新型生产工具与协同流设计，而非自封 AI PM）。
* **五大设计原则**：
  1. **不局限于医疗**：医疗是解决高复杂度问题的代表性场景，不是职业边界；
  2. **不堆砌黑话**：拒绝抽象的"自证式标签"，用真实问题和决策说话；
  3. **突出关键决策**：明确回答"我做出了什么产品决策，带来了什么变化"；
  4. **数据真实严谨**：剔除"0断流、100%"等争议修饰词，只留坚实可信的硬指标；
  5. **极致克制纯粹**：纯净中性黑曜石基底，视觉服务于信息扫描与阅读。

## 二、 整体视觉与交互样貌 (Visual & Interaction Appearance)

* **色彩基调（绝对中性黑曜石体系）**：
  * 画布底色：`#080808`（纯黑中性底，无任何紫偏）；
  * 卡片表面：`#121212`（深邃黑曜石，带 `1px` 半透明 `rgba(255,255,255,0.08)` 描边）；
  * 浮层悬浮：`#1a1a1a`（中性碳灰）；
  * 强调色三职责：`Lavender #d0bcff`（行动与控制）、`Mint #b9f2c8`（成果与指标）、`Pink #ffd8e4`（案例大标题）。
  * 色板变量的最终定义以 `DESIGN.md` 与 `variables.css` 为准。
* **字体排版层级**：
  * **Display**：`Anton`（用于首屏英文姓名与案例大标题，极强视觉张力）；
  * **Narrative / Lede**：`Merriweather` 衬线（用于核心主张与导语，提供编辑部杂志般的优雅品质）；
  * **Body**：`Hanken Grotesk`（高可读性现代无衬线正文）；
  * **Mono / Label**：`IBM Plex Mono`（用于编号、系统代码、字段与指标单位）。
* **页面交互形态**：
  * **全视口 Hero 开场**：无框沉浸式，GSAP 柔和渐显入场；
  * **Sticky Stack 案例堆叠**：3 张文件夹式大卡片在视口顶部依次吸附堆叠，左/右交替展现【系统蓝图图解 + 决策文本 + 指标】；
  * **极简横向/网格步进**：Career 与 Contact 采用无多余装饰的卡片流，节奏紧凑。

## 三、 分区块视觉与交互规范

> 每个区块的**逐字文案、信息层级与叙事**见 [`content.md`](./content.md) 对应章节；本节只定义呈现方式。

### 区块 01: HERO（舞台式开场）

#### 视觉呈现：
* 占据首屏 100svh，背景为纯黑与极淡的顶部冷白/薄荷微环境光；
* 顶部为固定的玻璃胶囊导航栏；
* 中间为大字体姓名与衬线核心主张，底部带下滑箭头与按钮引导。

#### 交互与动效：
* 柔和渐显入场（GSAP），首屏焦点是渐变 Display 姓名；
* 下滑箭头引导进入 Selected Work。

---

### 区块 02: SELECTED WORK（精选案例 · 解决 3 种复杂度）

#### 视觉呈现：
* 连续 3 张黑曜石大卡片，采用 Sticky 堆叠吸附效果；
* 每张卡片包含：系统蓝图示意（左/右交替）、入口问题句、量化结果；
* 卡片采用文件夹式描边（顶部圆角 `24px`），悬停 `translateY(-2px)` + 薰衣草紫边框过渡。

#### 交互与动效：
* Sticky Stack：卡片滚动到视口顶部依次吸附堆叠，形成折叠/展开节奏；
* 每张卡片包含一个 `ProjectBlueprintCover` SVG（会员规则引擎 / 正畸状态漏斗 / PACS 人机闭环三种构图）。

---

### 区块 03: CAREER PATH（能力演进故事）

#### 视觉呈现：
* 垂直时间轴卡片，展示 4 个职业阶段；
* 重点表达 **"能力发生了什么变化（What Changed）"**，而不是简单的公司列表。

---

### 区块 04: CONTACT（合作与收尾）

#### 视觉呈现：
* 极简、宽敞的双栏收尾卡片，纯黑质感，直达联系方式；
* 提供简历下载入口（`resume.pdf` 位于 `docs/profile/resume.pdf`）。

## 四、 与内容/全局规范的边界

| 层 | 管什么 | 改哪里 |
| --- | --- | --- |
| 全局视觉基础 | 配色、字体、圆角、间距、组件风格 | `DESIGN.md` + `src/styles/variables.css` |
| 首页设计规范 | 首页布局、区块交互、动效、封面构图 | 本文档 + `src/components/` |
| 首页内容结构 | 逐字文案、区块叙事、指标表述 | `content.md` |
| 页面数据 | 渲染所用结构化数据 | `src/data/projects.js`（从 content.md 提炼） |

> **隔离红线**：本文档不写逐字文案；文案一律以 `content.md` 为唯一来源，禁止在此重复。
