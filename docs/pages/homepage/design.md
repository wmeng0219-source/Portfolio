## 2. 当前首页特例采用值

2026-10-15用户明确要求Hero满屏并移除按钮、继续精简卡片、优化履历与收紧联系区；本节替代旧Hero限高与交错履历卡；用户随后要求联系区也至少满屏，内部内容仍保持紧凑。

当前优先完善PC中文；语言切换入口暂时隐藏，英文资料与既有响应式保留，移动端及英文不再作为每轮专项优化范围。恢复方式与验证统一见[当前计划](../../superpowers/plans/current/2026-09-30-architecture-simplification-and-single-source-of-truth.md#英文暂缓2026-10-15)。

- **顶部姓名与导航**：姓名链接从胶囊内拆出，与胶囊同属fixed顶栏但独立定位；PC姓名左边缘距视窗32px、顶栏top16px、姓名局部top5px、点击高≥44px。采用与Hero拉丁姓名一致的Anton `20px/400`、字距`-.01em`、Heading色、opacity `.65`，不加底框或分隔线。Hero大标题绘制边界bottom≤0时显示；返回时只要大标题重新进入视窗便隐藏，隐藏状态不占布局、不进入键盘焦点或辅助技术树，点击返回Hero且保留键盘焦点交接。胶囊仍页面居中，移除姓名宽度变量、槽位与展开平移；菜单为职业历程→精选项目→联系，滚动高亮依据同一真实顺序。既有窄屏菜单保留，本轮不开展手机专项设计。
- **Hero**：`min-height:100dvh`、100vh回退，仍为min-height而非裁切固定height；桌面padding`112px 32px 96px`、≤860px为`104px 20px 88px`；高度≤600px上下96px，保持最小屏高，内容过高时自然增加。HeroCopy仍max1040px，大姓名字体不变，移除其下中文辅助姓名；定位句与大姓名间20px。不渲染双CTA，向下提示进入职业历程；大姓名完全离场时隐藏提示，同时显示顶部独立姓名。
- **作品入口**：整卡保留既有文件夹轮廓、图文交替、hover及有条件sticky；卡片正文仅项目名、既有价值短句与入口。删除标签、证据数据块和口径说明的首页呈现，详情中仍保留证据。媒体比例16:9，未脱敏素材仍为中性占位，仅图标与“截图待补充”一行，辅助名称保留项目用途，去除重复的可见媒体标题。标题与摘要间12px，入口上距20px，不增加新宣传措辞。
- **职业历程**：max960px开放列表整体居中，章标题居中并与其他首页章标题共用中轴、标题组后36px；行内日期220px/职位与能力剩余列，左对齐、列距32px，行内上下28px、职位与能力间12px。日期13px/1.6 Utility、tabular-nums、Muted；职位20px/1.5/500，能力14px/1.8、Secondary，普通文本列表按4px行距/16px列距自然换行，尽量保持每个能力短语完整。各行中性细线分组，无节点光圈、交错、底卡或hover位移。≤860px日期180px、列距24px、上下24px、职位18px；≤560px单列、组内8px、日期无额外上距。四段日期、岗位和能力文字均按content.md，最近经历不暗示在职。
- **联系收尾**：区块`min-height:100dvh`并保留100vh回退，padding`96px 0`，flex垂直居中；内容超高时自然增长，不裁切。内部max960px，上内距0，移除顶部跨区分割线。所有尺寸均采用单列居中构图：标题/说明居中，渠道组在其下、max480px并居中，组间32px，渠道内部左对齐。标题至说明12px，渠道gap16px、标签至操作8px、操作min56px、16px字号；复制反馈置于两渠道之后，预留1.65em，长错误信息自然增高。≤860px组间28px、顶内距32px、区块padding`32px 0 56px`。本次按用户纠正恢复首页共同中轴，替代上一轮标题左对齐与联系左右栏。

## 3. 证据边界

卡片用已确认价值说明帮助选择；数据、完整口径、职责与归因限制留在对应案例正文。移除首页数据块不改变事实，也不恢复旧正畸累计预约数据或把同期观察写成单一成果。本轮已核对履历事实库，四段精确月份及最近正式岗位无冲突，不改岗位名称。

真实脱敏封面未就绪时保持明确名称占位，不伪造界面；素材状态由[content-readiness.md](../../project/content-readiness.md)维护。
