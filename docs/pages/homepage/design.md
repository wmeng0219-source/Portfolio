# 首页设计说明

> 2026-11-06 职责整理。正式内容与就近配图论点：[content.md](content.md)；通用值：[DESIGN.md](../../../DESIGN.md)；用途及状态：[COMPONENTS.md](../../../COMPONENTS.md)。本轮只整理规范，不改变页面、文案或已有审核结论。

## 1. 页面目标

让已看过简历的读者快速识别作者并选择相关案例。页面用于身份识别与作品选择，完整问题、判断、职责和证据留在详情；不重复履历初筛，不折叠或截断已确认信息。

## 2. 构图与阅读组织

顺序为Hero → 职业历程 → 精选项目 → 联系；项目顺序及正式文字只取content.md。采用DESIGN的Homepage场景、容器与字体角色，组件按COMPONENTS：首页专用组合模块。章节组共用中轴，履历列表和卡片内部使用局部左轴。

Hero与联系区的屏高、独立姓名交接、精简项目入口、履历列表是本页特例，见§4；不推广案例页。当前粒子姓名与AnimatedContent覆盖旧整组入场，不叠加旧动画。

## 3. 内容视觉化

| 内容位置 | 信息关系 | 载体及选择理由 | 语义边界 |
| --- | --- | --- | --- |
| Hero | 身份与定位 | 姓名与短句的排版构图；粒子仅承载姓名 | 不新增人物或产品证据；保留语义标题与静态回退 |
| 职业历程 | 时间与职责对应 | 开放列表，日期与职位／能力分列 | 不用交错卡片制造额外层级；月份与岗位不改 |
| 精选项目 | 选择入口 | 项目名、价值短句、封面与入口 | 不恢复已删除标签、数字和口径块，不添加宣传结论 |
| 联系 | 可采取的行动 | 紧凑渠道组 | 反馈就近显示，不新增联系渠道 |

视觉化选择引用DESIGN §4.7；首页封面用于识别，不作为详情真实界面证据。

## 4. 局部特例

<a id="2-当前首页特例采用值"></a>

作用域仅限首页。以下保留此前用户确认的布局与数值；HeroCopy上限、姓名绘制与配色被随后粒子条目覆盖，其它值不变。

- **顶部姓名与导航**：姓名链接从胶囊内拆出，与胶囊同属fixed顶栏但独立定位；PC姓名左边缘距视窗32px、顶栏top16px、姓名局部top5px、点击高≥44px。采用与Hero拉丁姓名一致的Anton `20px/400`、字距`-.01em`、Heading色、opacity `.65`，不加底框或分隔线。Hero大标题绘制边界bottom≤0时显示；返回时只要大标题重新进入视窗便隐藏，隐藏状态不占布局、不进入键盘焦点或辅助技术树，点击返回Hero且保留键盘焦点交接。胶囊仍页面居中，移除姓名宽度变量、槽位与展开平移；菜单为职业历程→精选项目→联系，滚动高亮依据同一真实顺序。既有窄屏菜单保留，本轮不开展手机专项设计。
- **Hero**：`min-height:100dvh`、100vh回退，仍为min-height而非裁切固定height；桌面padding`112px 32px 96px`、≤860px为`104px 20px 88px`；高度≤600px上下96px，保持最小屏高，内容过高时自然增加。HeroCopy宽度与姓名绘制引用下方ParticleTitle当前采用，移除其下中文辅助姓名；定位句与大姓名间20px。不渲染双CTA，向下提示进入职业历程；大姓名完全离场时隐藏提示，同时显示顶部独立姓名。
- **作品入口**：整卡保留既有文件夹轮廓、图文交替、hover及有条件sticky；卡片正文仅项目名、既有价值短句与入口。删除标签、证据数据块和口径说明的首页呈现，详情中仍保留证据。媒体比例16:9，未脱敏素材仍为中性占位，仅图标与“截图待补充”一行，辅助名称保留项目用途，去除重复的可见媒体标题。标题与摘要间12px，入口上距20px，不增加新宣传措辞。
- **职业历程**：max960px开放列表整体居中，章标题居中并与其他首页章标题共用中轴、标题组后36px；行内日期220px/职位与能力剩余列，左对齐、列距32px，行内上下28px、职位与能力间12px。日期13px/1.6 Utility、tabular-nums、Muted；职位20px/1.5/500，能力14px/1.8、Secondary，普通文本列表按4px行距/16px列距自然换行，尽量保持每个能力短语完整。各行中性细线分组，无节点光圈、交错、底卡或hover位移。≤860px日期180px、列距24px、上下24px、职位18px；≤560px单列、组内8px、日期无额外上距。四段日期、岗位和能力文字均按content.md，最近经历不暗示在职。
- **联系收尾**：区块`min-height:100dvh`并保留100vh回退，padding`96px 0`，flex垂直居中；内容超高时自然增长，不裁切。内部max960px，上内距0，移除顶部跨区分割线。所有尺寸均采用单列居中构图：标题/说明居中，渠道组在其下、max480px并居中，组间32px，渠道内部左对齐。标题至说明12px，渠道gap16px、标签至操作8px、操作min56px、16px字号；复制反馈置于两渠道之后，预留1.65em，长错误信息自然增高。≤860px组间28px、顶内距32px、区块padding`32px 0 56px`。本次按用户纠正恢复首页共同中轴，替代上一轮标题左对齐与联系左右栏。

### AnimatedContent当前采用

适用于Hero中文说明、履历标题与各行、精选项目标题及图文、联系标题与渠道；Hero姓名由ParticleTitle负责。采用纵向100px、0.8s、power3.out、opacity 0→1、元素顶部到视口90%触发、每次挂载一次，无额外延迟或逐行stagger。外层保留sticky链接和ol/li语义，标题覆盖与入场容器分离；完成释放filter/transform，卸载revert；初始化reduce显示最终态。

这项保留用户“用原版”的采用决定；不把之前额外的偏好实时监听和聚焦即时完成当作当前功能。与通用reduce实时要求的差距见当前计划。

### ParticleTitle当前采用

仅覆盖WEN MENG绘制：Anton400，字号clamp(96px,20cqw,232px)，HeroCopy最大1200px，目标标题框高clamp(160px,24cqw,280px)；粒子态取消原静态scaleY和背景裁字、局部容器min-height为0。静态回退继续引用DESIGN §3.2的原姓名角色及原有样式，不强行套粒子字号。

- 静止文字#ffffff；开场introColor与hover highlightColor均为#9edbb3。局部粒子色不改全站强调色。
- density4、particleSize2.2、scatter340、pointerRepel42、repelRadius120、idleDrift0.8、maxParticles10000、click burstStrength1.8。其余gather1600／stagger420／clickBurst／glow等沿用原版；保留聚合、漂移、排斥和点击互动。
- fullScreen绘制区域覆盖整个Hero；开场起点独立分布在该区域，目标仍取标题框中心与宽度，绘制层随Hero滚动；不使用fixed盖住后续内容。坐标换算与ResizeObserver随Hero尺寸更新。
- 保留h1辅助名称及Navbar交接钩子；减少动态、Canvas或观察器能力不足时静态回退，偏好变化即时处理。底层局部容量与坐标适配的来源记录见源码目录README，不再声称JSX逐字未改。

上面是最终有效配置；中间Hanken字形、稀疏采样、高饱和绿色、仅标题框散开等已被替代，见历史快照。
