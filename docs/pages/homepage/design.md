# 首页设计说明

> 2026-11-19 规范精简。本文记录当前页面的设计理由、素材与审核状态；正式内容见[content.md](content.md)，唯一设计规范见[DESIGN.md](../../../DESIGN.md)。本轮只调整文档职责，不改页面或既有验收结论。

## 1. 页面目标

让已看过简历的读者快速识别作者并选择相关案例。页面用于身份识别与作品选择，完整问题、判断、职责和证据留在详情；不重复履历初筛，不折叠或截断已确认信息。

## 2. 构图与阅读组织

顺序为Hero → 职业历程 → 精选项目 → 联系；项目顺序及正式文字只取content.md。沿用统一的色彩与字体基础，首页模块按本页阅读任务组合。章节组共用中轴，履历列表和卡片内部使用局部左轴。

当前方案以独立姓名交接、精简项目入口和开放履历列表组织阅读；行为见第 4 节。这些是当前设计记录，后续构图可依据内容与实页效果调整。

## 3. 内容视觉化

| 内容位置 | 信息关系 | 载体及选择理由 | 语义边界 |
| --- | --- | --- | --- |
| Hero | 身份与定位 | 姓名与短句的排版构图；粒子仅承载姓名 | 身份识别为主，保留语义标题与静态回退 |
| 职业历程 | 时间与职责对应 | 开放列表，日期与职位／能力分列 | 当前采用开放列表说明时间与职责；月份与岗位依据内容事实 |
| 精选项目 | 选择入口 | 项目名、价值短句、封面与入口 | 当前入口精简，详细数字与口径放在案例中，表述有事实依据 |
| 联系 | 可采取的行动 | 紧凑渠道组 | 反馈就近显示，不新增联系渠道 |

首页封面用于识别，不作为详情真实界面证据；表达方式按统一规范和本页阅读任务选择。

## 4. 当前呈现与阅读行为

当前首页保留以下设计关系；具体字号、屏高、列宽和动效参数是实现现状，可在统一基础上校准。

<a id="2-当前首页特例采用值"></a>

- 姓名与短定位句构成首屏，当前没有双 CTA；滚动提示进入职业历程。大姓名离场后，顶部独立姓名出现并可返回首屏，隐藏时不占键盘焦点。
- 职业历程是开放列表；项目入口包含项目名、价值短句、封面与入口，图文交替。当前作品卡保留有条件的 sticky，空间不足时自然滚动。
- 联系区采用居中标题与渠道组；邮箱与微信可获取，复制结果和失败说明就近呈现。
- ParticleTitle 负责姓名，AnimatedContent 负责其余既有入场；语义标题和静态回退保留。精确参数由现有组件实现承载，旧参数见精简前记录，不作为新的全站约束。
- AnimatedContent 对动态偏好实时变化的支持差距仍留在当前计划；本轮未改动组件。
