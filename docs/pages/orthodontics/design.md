# 正畸筛查页面设计说明

> 2026-11-06 职责整理。正式内容与就近配图论点：[content.md](content.md)；通用值：[DESIGN.md](../../../DESIGN.md)；用途及状态：[COMPONENTS.md](../../../COMPONENTS.md)。本轮只整理规范，不改变页面、文案或已有审核结论。

## 1. 页面目标

帮助陌生读者理解推荐范围、执行任务、跨角色记录与后续沟通的区别，判断作者如何把协作规则落实到可持续的工作安排。保留原六章内容与反思，不把业务阶段画成每位患者必经的临床路径。

## 2. 构图与阅读组织

采用DESIGN §4.6主案例双轨同宽及分隔章节节奏：深色自然高度封面、白色连续阅读、邻接目录。正文、标题、图形、图注及来源共用文章左右边界；已取消690px文字上限，不恢复“宽图窄文”。字号和间距均引用该配方及正文角色。

六章按“章节用途 → 判断或机制 → 解释 → 关系或证据”阅读；章标题与判断标题分层。COMPONENTS的Reader、ChapterHeading和Diagram目前仍由本页实现。无模拟窗口、装饰卡片或逐节入场。

Figma是参考证据：[用户指定文件](https://www.figma.com/design/Ya99yCoVxiOr5SjaMCbGKG/portfolio?node-id=622-2059)。参考原尺寸不与当前配方并列生效；被替代的窄文字列与过程记录见历史快照。本轮不重新访问或修改Figma。

## 3. 内容视觉化

| 内容位置 | 信息关系／载体 | 选择理由与必须保留的语义 |
| --- | --- | --- |
| content §01 | 自然高度封面、正文概览及职责／周期 | 封面保留成果摘要；正文有独立概览标题；正式内容不因布局重写 |
| §02 | 旧新机制同尺度对照 | 入口／角色任务／过程追踪三个维度，原流程与原因文字保留；旧快筛已有结果与看板，不描述为无数据 |
| §03第三组判断 | 推荐范围与任务安排图 | 推荐池是候选范围，筛查任务是执行范围；系统在原有预约添加项目与医生主动补充是并列路径，不是定额补齐或病例先后 |
| §04第三组后 | 职责矩阵＋独立沟通带 | 护士、儿牙、正畸共同完善同一记录，不用方向箭头暗示固定临床顺序；诊间、报告承接、离店后另列，不误作记录字段或自动发送 |
| §05机制成果 | 等宽业务节点与记录依据 | 筛查、专业结论、后续业务逐行对应，不用收窄梯形、人数或临床箭头；区分筛查采集与后续收费资料节点 |
| §05上线与使用 | 分开的事实摘要 | 累计提交记录与上线范围分别表达；记录不等于去重人数，上线不等于逐店采纳率 |
| §05同期观察 | 共同量尺区间图 | 端点、周期、指标定义和来源取内容稿；不与累计统计串漏斗，不增加精确值或页面归因文案 |
| §06 | 三组连续短文 | 学习与判断用文字足够，不添加装饰图 |

图均标为规则／关系示意，不冒充系统截图或患者数据；每图有明确问题、编码规则与可读说明。通用选型引用DESIGN §4.7，图中文字与事实仍以content.md及事实底稿为准，不从参考图补新阶段或权限。

## 4. 局部特例

仅作用于`/project/orthodontics`；共享配方已有值不复写。

| 编号比例 | 编号字号公式为`calc(章名字号 * 1.3 + 23px)`，不是跟随长章名总高度放大；PC角色引用DESIGN §4.6 |
| 小屏标题（≤560px） | 章名26px/1.3、编号公式额外值18px（约51.8px）；组后20px；眉题10px/1.3、.08em、眉题后5px；编号间距唯一引用DESIGN §3.4 |
| 章导语 | 18px/30px、段后24px；原长结论句作为导语，不替代用途型章标题 |
| 图注与来源 | 图注引用Caption字阶、左对齐；图→图注16px，多段图注间8px，来源上距12px；覆盖通用图注距离，保持图文同轴 |
| 图内角色与字号 | 范围标题及沟通场景20px/600、角色16px/600、安排路径标题14px/600、任务／域标签14px、连接说明13px；不按角色轮换品牌色 |
| 推荐／职责图 | 推荐范围节点中性浅底、6px圆角；共同记录表头中性浅底；职责矩阵角色列140px、手机80px，贡献列保留剩余宽度；手机推荐图按候选→两种安排→执行范围纵排，沟通纵排 |
| 旧新对照与业务追踪 | 对照列头中性浅底，手机保留左右对照、维度标题占整行；业务节点等宽，手机每节点与依据成组纵排 |
| 上线／使用事实摘要 | 数字clamp(36px,4vw,48px)/1.2/600、Heading/data ink；说明14px/1.8、列距18px、内距28px、中性浅底6px圆角；手机单列、内距24px |
| 同期区间编码 | 共用0–100%轴，区间端点来自content.md；当前观察用小范围Identity标记，端点／描边用Heading/data ink，数字16px/600/tabular-nums |
| 导航 | PC锚点预留引用DESIGN §5.6；手机132px，仅scroll-margin一处；手机目录固定在64px顶栏下。overview定位正文概览，case-cover单独封面；case-introduction兼容overview，system兼容solution；章节各有H2、概览职责／周期H3 |

图形白底、Action ink细线／箭头／方案边框；使用COMPONENTS职责矩阵与区间表达语义，不把通用节点圆角强制套到已确认局部图形。原移动方案保留，不表示本轮开展专项适配。
