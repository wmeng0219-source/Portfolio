# 正畸筛查页面设计说明

> 2026-11-19 规范精简。本文记录当前页面的设计理由、素材与审核状态；正式内容见[content.md](content.md)，唯一设计规范见[DESIGN.md](../../../DESIGN.md)。本轮只调整文档职责，不改页面或既有验收结论。

## 1. 页面目标

面向不熟悉口腔医疗业务的招聘者与用人经理，用 10–15 秒说明：这个项目把依赖个人判断和分散沟通的矫正前筛查，组织成能在门店运行的多角色协作流程；作者承担了门店调研、规则与流程、PRD、交互与界面、开发协调和上线推进。

阅读后应能回答三件事：

1. 业务原流程为什么难以持续执行；
2. 两个关键判断分别解决了什么问题，真实界面如何承载；
3. 项目上线到什么范围、哪些数字是记录、哪些只是同期业务变化。

页面不把作者描述成医疗诊断者；专业结论由正畸医生负责，患者沟通与最终转化由门店和业务团队推进。

## 2. 构图与阅读组织

采用「深色自然高度封面 + 浅色连续阅读 + 邻接目录」的既有案例壳，改为封面加六个阅读章节：

1. 业务挑战：旧流程为什么难以持续；
2. 决策 01：推荐候选与执行任务分离；
3. 决策 02：按专业边界拆分、多角色接续；
4. 诊间解释与家长报告；
5. 上线结果；
6. 反思。

当前阅读区将目录、正文与证据分组组织；章节标题、导语和图形解释建立层级。具体宽度和间距按统一规范与实页效果校准，完整截图与关键细节分别分配空间。

首屏封面保留黑色底、粉色标题和紫色强调，但不堆放长时间线或临床术语。封面事实只保留两项：**2026.02 全部门店上线**、**18,460 条累计提交筛查结论记录**；职责与周期在同一封面底部交代。

## 3. 内容视觉化

| 内容位置 | 信息关系／载体 | 选择理由与必须保留的语义 |
| --- | --- | --- |
| 封面 | 标题、定位句、职责、两项事实、合作边界 | 招聘者先看项目价值与本人职责；数字单位和口径紧跟数字，不用无来源的“提升” |
| 01 业务挑战 | 旧流程四步示意＋三个问题 | 四步只表示常见路径，标注“实际执行因门店而异”；三个问题分别对应重叠、角色、追踪，不写成长篇背景 |
| 02 决策 01 | 诉求／判断／最终规则三栏＋候选与执行范围图＋真实列表主图＋入口整合补充 | 三栏直接保留取舍逻辑；图只区分候选范围与执行范围，不画定额补齐；主图用两个编号框分别指认“已预约”和“推荐”区域 |
| 03 决策 02 | 旧表单问题／判断两栏＋四角色接续图＋三段角色证据＋试点精简 | 角色图把“接续”和“同一份记录”分开表达；不暗示所有病例一次完成或固定临床顺序；每段证据只指认该角色的关键动作 |
| 04 诊间解释与报告 | 口扫分析主图＋科普弹窗辅助图＋生成报告预览＋家长报告封面＋报告结构清单 | 口扫模型用于诊间讲解；科普说明辅助沟通，不替代诊断；报告承接结论，由顾问发送；长报告完整版放在放大层 |
| 05 上线结果 | 五段时间线＋三项事实带＋同期区间图＋口径说明 | 记录数、上线范围、同期成交率分栏；区间图共用 0–100% 轴；明确不能单独归因，也不把累计记录与成交率串成漏斗 |
| 06 反思 | 两条短文＋入口复用折叠 | 反思回答“下一次怎么做得更好”，不重复项目介绍；入口复用作为补充，不占正文主轴 |

图均标注为规则／关系示意，不冒充系统截图；真实截图只提炼源稿事实，不新增门槛、自动消息或审批动作。

## 4. 当前呈现与阅读行为

当前采用左目录、连续正文、编号章节、真实截图标注与报告查看。原固定尺寸不再作为本页独立规范；目录距离、字阶、媒体宽度与图文安排可按实页效果调整。

- 桌面目录随阅读定位，窄屏保留既有目录方式；旧锚点 `problem/thinking/solution/impact/overview` 继续映射到新章节。
- 截图标注只指认真实操作区，图例与编号对应；密集桌面截图当前支持局部横向平移及放大，后续仍需以重点可读性判断展示方式。
- 家长报告以正文预览、结构说明与完整长图配合；放大层允许纵向滚动，Escape、关闭按钮和图外区域可退出，关闭后返回触发焦点与原阅读位置。
- 截图只加载已处理的公开资源，素材与授权状态以第 5、6 节和证据清单为准。
- 本页证据与放大层源码见 [Evidence.jsx](../../../src/pages/cases/Orthodontics/Evidence.jsx)，业务图形见 [visuals.jsx](../../../src/pages/cases/Orthodontics/visuals.jsx)。
