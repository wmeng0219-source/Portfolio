## 2. 本页特例采用值（仅覆盖 `/project/orthodontics`）

### 2.1 容器与阅读栅格

- **封面与正文外层**：深色自然高度封面（顶部 100px / 底部 52px），白色正文及两侧留白铺满视口（`body` / `sheet` 均为 `#ffffff`，无外框黑边与整体圆角）。
- **共同居中容器**：封面与正文共用 `max-width: 1320px`（含左右 48px，居中），超宽屏不再将目录贴到视口远端。
- **响应式栅格（2026-10-15用户确认Figma适配）**：
  - `≥1080px`：正文两轨 `180px 目录 / 剩余文章区`，列 `gap: 48px`，移除正文原平衡空列；文章章节、图形、连续文字、小标题与来源共用最大938px宽度和左右边界；取消原690px文字上限（2026-10-24用户返修）。封面保留既有三轨及672px文字轴，不扩大首屏。
  - `861–1079px`：两轨 `180px 目录 / 剩余阅读区`，左右 `padding: 32px`、`gap: 40px`。
  - `≤860px`：单列，左右 `padding: 22px`；手机目录固定在 64px 顶栏下。
- **阅读区与章节间距**：阅读区上下 `64px / 80px`（手机 `40px / 64px`）；章前 `64px`、顶部 `1px` 中性线及 `24px` 留白；判断组之间 `32px`。段落连接不再叠加88px章前与32px顶留白。

### 2.2 本页局部字阶与对齐

- **封面标题校准（672px 阅读轴）**：
  - 中文：`Noto Sans SC` `clamp(36px, 3.5vw, 50px)` / `700` / `1.25`，自然换行，防止单字孤行。
  - 英文：`Anton` `clamp(32px, 3.2vw, 48px)` / `400` / `1.1`，桌面优先两行、手机自然增高。
- **封面介绍与元信息**：简介 `clamp(16px, 1.5vw, 19px)` / `1.8`；元信息 `14px / 1.65`、行间 `8px`；眉题、标题、简介、元信息顺序排列，组间 `24px`。
- **封面成果摘要**：元信息后单段开放文字，`14px / 1.65 / #f5f5f5`，强调字重 `500`；上距 `24px`，顶部 `#2b2b2b` 细线及 `20px` 上内边距。自然换行，内容引用content.md。
- **正文层级**：
  - **六章标题组（2026-10-15，按用户提供的标题截图与Figma适配）**：左侧编号，右侧英文眉题与章名上下排布；共用同一组件，包含正文开头的“01 项目概览”。外边界仍与正文及宽图形共用左轴，不把编号伸入目录列。
  - **比例校准（2026-10-15用户返修）**：编号与右侧“眉题＋单行章名”的实际字面近似等高，不能只让顶部对齐后任意放大编号；长章名换行时编号不随整组拉长。
  - 章号：`Anton` / `400` / `.95`，字号随章名为`calc(章名字号 * 1.3 + 23px)`（桌面59.4px），字距`-.025em`、tabular-nums。颜色与眉题统一采用现有Action ink `#624595`，替代灰紫装饰色，不使用透明叠色或渐变。
  - 标题组采用`70px / minmax(0,1fr)`两列、列距`16px`，顶对齐、右列无额外上内边距；组后`28px`。编号槽固定，避免Anton的01/02字面宽度不同导致章名横向跳动。眉题`IBM Plex Mono` / `12px` / `500` / `1.3`，字距`.08em`，眉题后`6px`。
  - 章标题：中文`28px` / `700` / `1.3`、`#171717`；英文沿用Hanken结构字体。深色参考图的白字和暗紫编号不直接搬到白底，采用以上浅色阅读变体；不改变已确认章名。
  - `≤560px`：编号约`51.8px`（公式额外值改为18px）、编号槽`56px`、列距`12px`、组后`20px`；眉题`10px/1.3`、字距`.08em`、眉题后`5px`；章名`26px/1.3`。长章名自然换行，标题组由内容增高，不裁字或缩放整组。
  - 章导语：`18px` / `30px`、段后 `24px`；原长结论句作为章内导语，不与用途型章标题混用。
  - 小标题与概览职责/周期标题：`clamp(18px, 1.4vw, 20px)` / `600` / `1.5`，标题后 `12px`；概览职责标题前 `32px`，小标题使用 `text-wrap: wrap`，按实际宽度自然换行。
  - 解释正文：`16px` / `28px`，段后 `16px`；中文正文两端对齐且末行左对齐，英文左对齐，图内说明左对齐；正文显式使用 `text-wrap: wrap`，覆盖全局pretty换行规则。

### 2.3 导航与章节映射

目录与右侧主章标题统一采用六项内容用途名称：`项目概览 / 问题分析 / 我的判断 / 整体方案 / 落地与业务结果 / 反思`。锚点安全距离桌面 `100px`、手机 `132px`（仅设置一次 `scroll-margin`），定位后焦点交给章标题，沿用离散 `IntersectionObserver` 高亮与 `prefers-reduced-motion` 即时定位。

`#overview`现定位正文“01 项目概览”及`overview-title`焦点；封面单独使用`#case-cover`，深浅顶栏继续以封面离场判断。旧`#case-introduction`兼容到`#overview`，旧`#system`仍兼容到方案；六章各有一个H2，概览内职责与周期使用H3。英文眉题是辅助设计标签，中文章名及完整正文不改；英文模式概览/问题眉题采用不同措辞，避免与英文主标题逐字重复。

| 章节 | 呈现 |
| --- | --- |
| 项目概览 | 自然高度封面；正文01标题、完整背景、职责与周期，成果摘要仍在封面 |
| 问题分析 | 问题导语、旧新机制三个维度对照、原流程与两组原因；保留旧快筛已有看板的事实 |
