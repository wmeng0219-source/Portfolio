## 二、 视觉与交互要点

### 指标呈现
- 首屏指标卡（`Mint #b9f2c8` 标记成果）：
  - 全门店正畸成交转化率：`30-40%`（2025.02-04）→ `50-60%`（2026.02-04）
  - 指标口径：全门店正畸成交转化率，需标注对比周期。
- 指标数字与 `docs/project/正畸筛查与状态管理.md` 保持一致。

### 机制可视化
- **核心可视化对象**：状态机漏斗（未筛查 → 筛查中 → 待结论 → 需矫 → 推进中 → 已预约 → 完成）与多角色协作链（护士 / 儿牙 / 正畸 / 运营）。
- 推荐使用 `ProjectBlueprintCover`（五段状态轴 + 回流路径构图）。
- 优先级表达（牙列干预窗口排序）用层级/编号呈现。

### 交互形态
- 多角色职责（护士 / 儿牙医生 / 正畸医生 / 运营）用角色分工对照区块。
- 策略演进（初版"要求更多" → 试点反馈 → 主动做减法）用 Before / After 对照。
- 资料有效期（面相 6 个月、口扫/全景 1 年）用状态提示呈现。
