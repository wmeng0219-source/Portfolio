# 项目内容就绪度清单

> 用途：记录项目事实进入作品集案例前的证据状态。本文不新增项目结论；“待补”表示需要回到原始材料、项目参与者或正式报表确认，不能直接作为页面文案。
> 
> **母稿状态**：全部 4 个项目已在 [`docs/pages/`](../pages/README.md) 完成页面内容母稿建立，待补项一旦补充，需同步更新对应 `content.md` 母稿及 `src/data/projects.js`。

## 使用方式

- `已具备`：对应项目主文档已有可追溯事实，且已在 `docs/pages/` 形成标准 7 步叙事母稿。
- `待补`：材料方向明确，但尚未具备可展示或可核验的来源。
- `谨慎表述`：可保留为阶段性描述，但不得扩展为强因果结论。

回填时先更新项目事实主文档与 `docs/pages/` 对应 `content.md` 母稿，再在本清单附上来源路径和更新时间。

## 准入规则

- 进入首页主案例：核心命题、责任边界、至少一组有口径的结果、两个决策证据、关键素材均已具备。
- 进入详情页：满足首页主案例要求，或能以明确的“进行中/阶段性验证”定位呈现，且不得虚构结果。
- 进入扩展案例：至少具备清晰问题、个人边界、一个可展示机制和一项待验证说明。
- 任何缺少来源的内容：仅保留在事实整理阶段，不进入页面。
