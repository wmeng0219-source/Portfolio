## 什么时候更新

只有实际事实、职责、指标口径、来源或证据变化时更新本层。单纯修改标题、摘要、章节或排版不要求重写事实底稿。

1. 新材料保存在 origin 或相应资产目录；真实患者等信息须脱敏。
2. 在相关事实底稿记录来源、范围和确认依据，区分已确认事实、设计推理与未验证方向。
3. 证据状态变化写入 [content-readiness.md](content-readiness.md)，不要在多个计划复制同一缺口。
4. 相应内容稿由用户审核，设计确认后由 AI 实现和核对。

## 核查边界

- 不虚构研究、反馈、推进、数据或上线功能，不夸大个人贡献。
- 数字记录指标定义、分母、样本、周期、来源与归因限制；目标、规模与实际效果分开表达。
- 事实缺口不以模板补写，也不强制把全部材料组织成相同章节。
- 已确认页面稿与事实有冲突时列明来源请用户核对，不用旧计划或代码替用户决定。
- 原始资料保留追溯，默认仅读相关案例，不扫描全部材料。
